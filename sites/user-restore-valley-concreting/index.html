Five jobs, one set-out standard.

Concrete is unforgiving, the level you set at 7am is the level the client walks on for the next twenty years. These are the jobs Valley Concreting takes on.

Driveways & crossovers

Set out to the kerb line, formed, reinforced and poured in panels so the joints land where the cars actually drive. Broom or exposed finish, with the fall running away from the garage.

Formwork, mesh, control joints

Shed & house slabs

Level pads for sheds, extensions and outbuildings. Set out square, checked on the diagonals, with the slab edge finished clean for whatever gets fixed down on top.

Square & diagonal check, edge finish

Paths, patios & entertaining areas

Poured paths and patio slabs that tie into existing levels instead of sitting proud of them. Saw-cut joints run on a set pattern so the surface reads as one piece.

Saw-cut joints, tie-in levels

Exposed aggregate

Aggregate exposed while the concrete is still green, then washed and sealed. Non-slip underfoot and it hides the marks a plain broom finish keeps for years.

Wash-off, sealed

Slab replacement & repair
