A carpentry crew you can hand a set of plans to

JE Carpentry & Linings is a Perth carpentry outfit working on new builds and renovations. We take on the framing, get the linings right, and finish the fit-out, so the same crew is on the job from set-out to handover.

Work is set out from the drawings, checked as it goes, and left tidy. If a detail on site needs sorting, it gets sorted on the spot rather than passed down the line.

  • Framing set out from the drawings, not from guesswork
  • Plasterboard and linings finished ready for paint
  • Fit-outs, doors and trim done by the same crew
  • Tidy sites and a clean handover
