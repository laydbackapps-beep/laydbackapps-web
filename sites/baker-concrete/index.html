Approach

Crafted with intent

Every pour starts with the formwork. We set tight, true formwork, place with discipline, and strike clean - revealing board-marked faces, crisp arrises, and surfaces that don't need explaining. The finish is in the setup.

// FORMWORK STRIKE DETAIL - panel peel revealing board-marked face

  • Formwork set plumb, braced and sealed - no blowouts, no bleed lines.
  • Concrete placed in lifts, consolidated properly, finished to the specified texture.
  • Control joints cut to plan, curing managed - no plastic shrinkage cracks.
  • Formwork struck at the right window - board grain reads clean, arris holds sharp.
  • Site left clean. The work speaks for itself.
