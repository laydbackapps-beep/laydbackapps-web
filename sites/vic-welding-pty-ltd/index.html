Method

How a joint gets worked

Three steps, in this order. Each one sets the next up.

Square and mark

Plate and section are squared, marked and set to the joint line before any arc is struck.

Tack and align

Tacks hold the joint true and square while the run is laid along the seam.

Run and dress

The bead is run along the joint, then dressed and cleaned back to the plate.
