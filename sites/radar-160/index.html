How a deck goes together

The order the work happens in, from the first line on the wall to the last board.

  1. Set outLevels off the doorThe deck height is taken off the door sill, so the step out is the size it should be and the boards land under the threshold.
  2. BearersPosts and bearersPosts set to the span, bearers fixed back to the house, and the frame squared before anything is laid on it.
  3. JoistsJoist spacingJoists run at the spacing the board direction needs, with the blocking in to keep them straight.
  4. DeckDecking and fallBoards laid with a consistent gap and the fall set so water runs off, not back to the wall.
  5. RailRails and screensCable rail, slat screens and the finish, fitted after the deck is down so the lines stay true.
