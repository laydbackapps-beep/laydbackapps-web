Four steps, in order, every time

The same sequence on every pour, from set out to the final float.

Set out and tie steel

The site is set out to the plan and the reinforcement grid is tied in place before anything is poured.

Set the formwork

Forms are set true to line and level so the finished edge runs straight.

Place the concrete

Concrete is placed and worked through the steel, filling the forms evenly.

Screed, float, finish

The surface is screeded to level, floated and finished ready for the next trade.
