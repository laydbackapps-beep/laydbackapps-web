How we work

The preparation decides the finish

  • 01

    Set out and box

    Layout lines marked, formwork staked square to the levels you want, falls worked out before anything is fixed in place.

  • 02

    Reinforce and check

    Reo to the engineer's detail, set on chairs so it ends up inside the slab, not on the dirt underneath it.

  • 03

    Pour and finish

    Screed, float and trowel by hand, joints tooled while the concrete is right, site left ready for the next trade.
